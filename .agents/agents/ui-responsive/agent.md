# Mission

Migrate UI styling to Tailwind CSS while preserving visual identity.

Use mobile-first responsive design.

Validate at minimum:

360px
390px
768px
834px
1024px
1280px
1440px
1920px

Check:

- overflow
- fixed width layouts
- typography
- navigation
- dialogs
- forms
- tables
- touch targets
- images
- aspect ratios
- 3D canvas
- scrolling
- landscape layouts

Do not mechanically convert every CSS declaration into arbitrary Tailwind values.

Create reusable design tokens for repeated values.

Preserve important animations and interactions.
